## 🚀 Overview

Human Leverage AI™ is an intelligent platform that combines cutting-edge AI capabilities with human-centered design to help users maximize their potential. Built on Next.js with Supabase backend and OpenAI integration, it delivers personalized AI-powered insights and tools.

## ✨ Features

- **AI-Powered Analysis** — Leverages OpenAI GPT models for intelligent recommendations and insights
- **Real-Time Data Processing** — Supabase-powered backend for instant data synchronization
- **Secure Payments** — Stripe integration for seamless subscription and payment handling
- **Responsive Design** — Fully responsive UI optimized for all devices
- **User Authentication** — Secure auth flow powered by Supabase Auth
- **Dashboard Analytics** — Comprehensive analytics and progress tracking

## 📦 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn
- Supabase account
- OpenAI API key
- Stripe account

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/godessgizelle143/Human-Leverage-AI-.git
   cd Human-Leverage-AI-
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env.local
   ```
   Fill in your API keys and configuration values in `.env.local`.

4. **Run the development server**
   ```bash
   npm run dev
   ```

5. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

### Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/godessgizelle143/Human-Leverage-AI-)

1. Push your code to GitHub
2. Connect your repository on Vercel
3. Add environment variables in Vercel dashboard
4. Deploy!

## 🔐 Environment Variables

See `.env.example` for all required environment variables. You'll need:

- Supabase project URL and keys
- OpenAI API key
- Stripe secret and publishable keys
